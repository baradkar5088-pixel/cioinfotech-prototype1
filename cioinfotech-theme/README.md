# CIO Infotech WordPress Theme

## Install
1. Start the CIO site in LocalWP.
2. Open the LocalWP site folder.
3. Navigate to `app/public/wp-content/themes/`.
4. Extract the `cioinfotech-theme` folder into `themes`.
5. In WordPress Admin, open **Appearance → Themes** and activate **CIO Infotech**.
6. Set the official logo in the Site Logo / Custom Logo setting.
7. Create a WordPress menu and assign it to **Primary Menu**.
8. Visit **Settings → Permalinks** and click **Save Changes**.
